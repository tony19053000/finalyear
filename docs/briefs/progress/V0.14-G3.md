## Deviations / decisions for the Lead
1. **Pruning rule.** The brief's literal rule (dominated on every term by an included node "with free capacity") would remove *useful* lanes: a node runs one lane (D267f), so an extra lane always adds throughput unless it gets no chunk. Implemented: B is pruned only when an already-included A is no worse on both lane terms, better on one, **and A alone finishes every item before B could start** (`start_A + items x per_item_A + max_chunks x t_o <= start_B`) - then B is inactive in every set it would be in (property-tested against the water filling over 60 seeded fabrics), so only strictly dominated sets go. Pruning is not needed for latency (p99 was 32 ms at 16 nodes before it).
2. **Old replays and pruning/link floor.** To keep every stored v1 replay exact (D307), `PlannerConfig` defaults are the pre-G3 behaviour (`min_useful_bw_bytes_s = 0`, `prune_dominated = False`); the dispatcher sets the configured values (pruning always on; no user setting for it). `snapshot_digest` omits G3 inputs while unset; `mf_planner_golden.fields_text` omits `Decision.objective/pruned` while unset.
3. **Unknown objective at submit** is `400 invalid_input` (the API's convention for every refused body, e.g. an unknown policy), not 422.
4. `env_error` and `transfer_error` count as node-caused (as the brief says), `timeout` as a workload failure (counted in the total only). An `env_error` caused by a bad requirements file will therefore count against the node it happened on - flagged as a follow-up (could require "succeeded elsewhere").
5. The predicted total (and `SplitPlan.predicted_makespan_s`, run records' `planner_estimate_s`) now includes the risk term (an expected time). **G2's calibration must not calibrate `risk`** (no phase) and should compare the un-risked total, or subtract `risk`; at the merge, calibration should be applied before risk is added (risk uses `T`).
6. CLI `compute run --objective` and the decisions API `pruned` field were added (small, needed for "explain can say why"; G5 extends the UI).

## Item 1 — per-node clock offset — done (`755527b`)

Deviation (documented): the exchange is the existing **Ping/Pong** (controller pings every lease interval,
6 s), not a heartbeat echo: controller wall at the Ping = `sent`, the Pong envelope's `sent_at` = agent
clock, `received` = `sent` + monotonic RTT (a controller wall step cannot fake the round trip). Works with
old agents (they already stamp `sent_at`); `Pong.clock_resolution_us` (new) widens the bound, unknown =
16 ms. `controller/session/clocks.py` (`NodeClock`, window 32 exchanges / 300 s, alert > 250 ms or
inconsistent after >= 4 exchanges, one per episode: `audit_event clock_uncertain` + live `alert`),
estimate rides on the RTT write (node_session clock columns, migration 0021), `NodeDetail.clock`.
Tests `tests/unit/controller/test_v09_g1_node_clock.py` (+5 s / -5 s / +1 h skew within bound, wall step,
stale tight exchange, alert once + recovery, no alert < 4 exchanges, agent step -> inconsistent).

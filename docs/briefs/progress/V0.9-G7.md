## Hand-off notes
- **No src change.** Nothing the test exercises misbehaved.
- **What "in flight at the kill" proved:** in all three runs the runs `submitted` at the SIGKILL were reconciled
  to `done` by the existing paths (the agents kept running them; no infra failure, no retry, no second ok
  record). The retry branch (infra failure -> `tries + 1`) is not forced here; it is covered by G5b's component
  tests. A lab kill with longer runs may hit it.
- **Labels are always `tie` and CVs ~0.15 on the harness:** all three "nodes" are processes on one 16-thread
  host, so configurations are statistically equal and noisy (most carry `cv_flag` at the 0.10 default). The test
  asserts labels are `best` or `tie` (never `pending` / `insufficient`) and only that a CV is reported
  (criterion 3), not a CV bound.
- **Brief wording:** §5i says `GET /v1/telemetry/export?campaign_id=`; the real query parameter is `campaign`.
- **Budget:** ~7 min 15 s per run of the file (brief budget ~12 min); not marked `slow`.
- **"Row count = measured runs":** the export has one row per attempt (205 = 204 ok + 1 pre-empted attempt); the
  test asserts rows = attempts = `status.records` and ok rows = done runs (one per run).

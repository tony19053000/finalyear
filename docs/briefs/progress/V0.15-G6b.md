## Decisions taken in the implementation (for the Lead)
- Old synchronous clients: the request must carry `background: true`; without it -> 400
  `eval_requires_background` with a clear message (an old CLI would otherwise misread a 202 silently).
- Concurrent starts: one evaluation per controller -> the second POST gets 409 `eval_already_running` (with the
  running `report_id`), not a queue.
- Restart detection assumes one controller per database (as the session sweep does). A running row this process
  is not running is answered `failed` / `controller_restart` even before a sweep (never stuck `running`).
- Stop: the controller cancels the evaluation (fold child killed) and writes `controller_restart` best-effort
  (5 s), else the next start-up sweep does.

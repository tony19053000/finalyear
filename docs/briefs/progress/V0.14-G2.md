## Choices (documented in code + docs)
- Too few runs (< 2 matched) or a fit with no factor -> **nothing written** (no all-1 version).
- Mode 3 sets never feed the fit (their stored terms blend lanes); one-lane split decisions feed `transfer`/`env` only; split `compute` and the Mode 3 extra terms are `no_phase` (factor 1).
- The refresh reads at most `20 x calibration_window_runs` newest matched decisions (cap 20 000).
- `pinned` status is allowed by the CHECK (brief) but G2 writes only active/rejected/superseded; the pin is the config setting.

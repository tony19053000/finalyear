## Decisions taken in the implementation (for the Lead)
1. **Token file in `/run/meshforge-console/token`**, not `/var/lib/meshforge/console/token` (brief §5c.2):
   `/var/lib/meshforge` is `0750 meshforge:meshforge`, so a `meshforge-admin` member could not traverse to it
   without loosening the state folder; `/run/meshforge-console` (systemd-tmpfiles, `2750
   meshforge:meshforge-admin`) gives the file the admin group by inheritance and is emptied at boot, which
   matches "token rotates on restart". Developer mode: `<data_dir>/console/token` `0600`.
2. **Launcher puts a one-time launch code in the URL, not the token** (`#c=<code>`, 60 s, single use): the
   `xdg-open` argv is visible to every local user in `ps`; the token itself never appears in a command line.
   The page still accepts `#t=<token>` (brief wording) for a user who reads the file by hand.
3. **No path unit; the service always runs** (G1 follow-up e): with the console the agent no longer exits
   `not_enrolled`; a supervisor keeps the console up and starts the fabric part once enrolled (console join, or
   `sudo meshforge-agent join` - the supervisor polls the enrolment), stops it on leave, restarts it in-process
   on request, and keeps the console up after a typed stop (revoked, conflict, config error) showing why.
   Console off (developer `meshforge-agent run`) = exactly the old behaviour and exit codes.
4. **"Give Docker access" cannot be a pkexec call from the service** (Q24): the service has
   `NoNewPrivileges=yes` (pkexec is setuid) and no desktop session (no polkit agent to ask the password).
   Any rule that lets the *service user* trigger it would let job code running as `meshforge` (unsandboxed
   runtimes) make itself root-equivalent. So: the console's Docker check says what to do and offers it
   two ways - the app-menu action "MeshForge: give Docker access" (`meshforge-console-open --docker-access`
   -> `pkexec` in the owner's session, OS password dialog, polkit action `org.meshforge.docker-access`) and
   the exact command to copy. The helper only runs `usermod -aG docker meshforge` + restarts the service.

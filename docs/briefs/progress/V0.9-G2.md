## D225 follow-ups (items 1, 3, 5; 2026-10-17)

  (`_seeded_model`: CPU generator only, inside `fork_rng` - the process RNG is untouched) - a separate object,
  never a copy of the timed model. Inference: weights + buffers bit-equal to the rebuild, full last-batch rerun
  equal, and rows of the last batch recomputed in float64 (whole batch within a 1e11-FLOP budget, else evenly

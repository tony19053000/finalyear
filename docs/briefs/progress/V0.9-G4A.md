## Deviations (justified)

1. **`condition` is VARCHAR(128)**, not the 64 of the other short text columns: a canonical netem condition
   with delay + loss + rate already reaches ~40 characters and lane B may add arguments; 128 leaves room
   without a later schema bump. Bounded like every text column (longer -> null, never cut).
2. **Lane B seam = the campaign identity mapping** (`condition` / `condition_measured` keys), not a new
   recorder read. Lane B decides where the measured values live; whatever it is, `campaign_identities` (one
   query in the recorder's transaction) is where it returns them. If lane B prefers attempt-level storage it
   can still set `RecordSource.condition*` from there - the builder only reads the two fields.
3. **0.8 touches `controller/jobs/planning.py` and `queue_reads.py`** (the brief lists `controller/jobs/decision*`):
   the shadow plan is in `planning.py`; the bench identity rule is reused from `queue_reads` (one prefix).
4. **0.5 semantics**: `count` = runs *submitted*; skipped / `already` runs are listed but do not count either
   (literal "until k submitted"), bounded by `MAX_EXAMINED` = 2 000 per call. Node-wide deferrals are listed
   **once per node per call** (otherwise an offline node holding 100 000 runs would list them all); the G3
   component assertion `["deferred"] * 2` (offline node, count 2) became `["deferred"]` for that reason.
5. **0.4 test changes**: the G3 tests that asserted the old behaviour (`Content-Length` equals the body; the
   export docstrings say "buffered in memory") now assert the new one. The OpenAPI response description still
   says "telemetry schema v1" - left unchanged on purpose (changing it regenerates `openapi.json` digest and
   `frontend/src/api/schema.d.ts`, which needs `npm ci` here; follow-up).
6. **0.1: both chunking and rebuild change** (the brief offers "chunk or narrow"): chunking alone could not
   reach 512 MB because the float64 copy of the whole model is 2.4 GB at the corner; the one-layer rebuild
   removes that and keeps the corner (no family limit narrowed).

# L4 -> L2: check QoS + set the ideal Windows settings

From L4 (Windows laptop). On Windows, MeshForge jobs ran 2-3x slower until two things were fixed. Please check that your laptop has both.

## Step 1: Turn on the High performance power plan
In an admin PowerShell window:
    powercfg /setactive SCHEME_MIN
    powercfg /getactivescheme
The second command should print "High performance".
L4 numbers: Balanced 154 s, High performance 85 s.

## Step 2: Check that the agent is on v0.17.5 with QoS working
In an admin PowerShell window:
    & "C:\Program Files\MeshForge\bin\meshforge-agent.cmd" policy show; Select-String -Path C:\ProgramData\MeshForge\logs\agent.log -Pattern 'qos' | select -Last 5 | % Line
Good result: you see agent.process.qos lines with applied=true (plus qos_self applied=true).
If you see no qos lines, the agent is older than 0.17.5: upgrade it first.

## Ideal settings (what L4 uses)
- Agent v0.17.5. It applies HighQoS to every job, which keeps jobs off the E-cores. L4 numbers: 164 s without it, 48 s with it.
- Power plan: High performance, with the laptop plugged in.
- CPU cap: none (leave the CPU field empty in setup).
- Jobs ON, GPU jobs ON, unsandboxed ON.
- "Share the GPU with programs on other laptops": OFF. Policy show should report accept_gpu_sessions False.

FAQ

Questions people ask.

What is hive?

hive joins the laptops you already have into one shared computer. One computer runs the controller, which coordinates the fabric and serves a web dashboard. Every laptop that shares its CPU or GPU runs the agent. You send a program, and hive decides where it runs best: on your laptop, on another one, or split across several.

Can other people run things on my laptop without asking?

No. After install a laptop joins but runs nobody's jobs until its owner turns on Run jobs from the fabric on this laptop. The owner, not the fabric's admin, also sets how much CPU and memory one job may use, whether the GPU is shared, and whether jobs may use the network. What your laptop shares

Does it work over the internet?

No. All laptops must be on the same network: home or team Wi-Fi, or Ethernet. On Windows, set your own network's profile to Private; on a network Windows calls Public, other laptops cannot fetch files from yours (jobs still run).

Which systems are supported?

Controller: Ubuntu 24.04, 64-bit. Laptops: Windows 10 (22H2) or 11, 64-bit, or Ubuntu 22.04 / 24.04, 64-bit. Docker and an NVIDIA GPU are optional; without them a laptop still shares its processor. There are no macOS packages.

Do I need Python, Docker or WSL?

Not to install. The Windows installer needs no Python, terminal or WSL; each Ubuntu package brings everything it needs. Your jobs run your own program, so the laptops that run them need what that program needs (for a Python job, Python). Docker is optional and lets jobs run in containers; giving the agent Docker access equals administrator rights, so it stays off until you choose it.

Windows says "Windows protected your PC". Is that expected?

Yes, the installer is not signed yet. Click More info, check that the app name is MeshForge-Agent-Setup-..., then Run anyway.

Where do I get a join code, and how long does it work?

The fabric admin makes one on the dashboard: Settings > Invites > New invite (or compute fabric invite in a terminal). A code starts with mf1-, works once, and only for a limited time (15 minutes by default). If it expired or was already used, ask for a new one.

Can the controller computer share its own CPU too?

Yes. One Ubuntu 24.04 computer may have both packages: meshforge-controller and meshforge-agent.

How does splitting a job across laptops work?

Add a split: section to compute.yaml. hive cuts the list of items into pieces, laptops pull pieces until all are done, and the results are joined in order. If splitting would be slower than one laptop, it runs on one and compute explain says why. Split one big job

Can my program use another laptop's GPU directly?

Not from inside your running program yet: the Python library for Remote GPU / Combined GPU comes with a later version. Today a job that needs a GPU (resources: gpu: required) runs on a laptop whose owner shares its GPU.

How do I upgrade?

Upgrade the controller first, then the laptops: install the new version over the old one, the same way you installed it. Settings and identity are kept, and if the new version does not start, hive switches back to the previous one by itself. Upgrade & uninstall

If I uninstall, is my data gone?

Not by default. sudo apt remove meshforge-agent (or answering No to Also remove all Hive data from this computer? on Windows) keeps the laptop's identity, so it comes back as the same node. Only apt purge, or Yes on Windows, removes everything; sudo apt purge meshforge-controller deletes the fabric.

Still stuck?

Collect the checks, the last 80 log lines and the installer's output, and send them to the team running your fabric.

meshforge-agent doctor                  # on the laptop (Windows: administrator PowerShell)
sudo meshforge-controller doctor        # on the controller
journalctl -u meshforge-agent -n 80     # the agent's recent log (Ubuntu)

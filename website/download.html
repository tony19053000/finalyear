hive for Windows

Shares this laptop's CPU, and its GPU if you allow it. Starts with Windows.

v0.17.5 · x64
hive-Setup-0.17.5.exe Download installer

The installer still carries the old name. You do not need Python, a terminal or WSL.

You need

  • Windows 10 (22H2) or Windows 1164-bit Intel or AMD processor
  • An administrator's passwordyours, if you are an administrator
  • A join codefrom whoever runs the fabric's controller
  • OptionalDocker Desktop and an NVIDIA GPU with its driver

Install in five steps

  1. Download hive-Setup-0.17.5.exe from your team's release page or the person running the fabric.
  2. Run it. If Windows says "Windows protected your PC": the installer is not signed yet. Click More info, check the app name is hive-Setup-..., then Run anyway. Click Yes when Windows asks whether the app may make changes.
  3. Follow the pages. Accept the licence and keep the suggested folder (C:\Program Files\hive). After install the laptop runs nobody's jobs until you allow it.
  4. Wait for "hive setup finished". The installer checks that it really runs (up to a minute). Leave Open hive ticked and click Finish.
  5. Join. A page served by the laptop itself opens. Paste the mf1-... code, or scan the dashboard's QR code with the webcam. Join a laptop →

The controller runs on Ubuntu 24.04 only. To start a new fabric, see the Ubuntu tab.

Every laptop that shares

Agent

Shares this computer's CPU/GPU with a fabric. Runs as the system service hive-agent.

Ubuntu 22.04 / 24.04
hive-agent_0.17.5_amd64.deb Download .deb

Then, in the download folder:

$ sudo apt install ./hive-agent_0.17.5_amd64.deb

apt needs the ./: it means "this file", not a package from the internet. Next, open the agent's page from the app menu (or run hive-console-open) and join.

One per fabric

Controller

Runs the fabric: dashboard, database, join codes. Install it once, on a computer that stays on.

Ubuntu 24.04 only
hive-controller_0.17.5_amd64.deb Download .deb

Then, in the download folder:

$ sudo apt install ./hive-controller_0.17.5_amd64.deb

It ends by telling you to run sudo hive-controller setup url. Continue with Create a fabric →

Check a download (optional)

In the download folder, with SHA256SUMS next to the files, this must say OK:

$ sha256sum -c SHA256SUMS --ignore-missing

Is it running?

systemctl status hive-agent          # or hive-controller
hive-agent doctor                    # version, joined or not, last upgrade, Docker/GPU/disk checks
sudo hive-controller doctor          # the controller's own checks
journalctl -u hive-agent -n 50       # the agent's recent log

One computer may have both packages: the controller can share its own CPU too. You do not need Python, Docker, PostgreSQL or a source checkout. Only Ubuntu 22.04/24.04 packages are built and tested; on other distributions the bundle hive-0.17.5-linux-x86_64.tar.xz can be run by hand, but that path is not tested.

Upgrade

Upgrade the controller first, then the laptops.

Install the new version over the old one. Settings and data are kept, and a version that does not start rolls back by itself.

Upgrade & uninstall guide →

Remove, keeping the data (default)

$ sudo apt remove hive-agent

Windows

Settings → Apps → Installed apps → hive Agent → Uninstall. Answer No to also remove all hive data? to keep the same node.

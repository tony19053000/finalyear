  ```powershell
  uv sync --all-extras
  uv run pytest tests/component/bench -m component -q -p no:cacheprovider
  uv run pytest tests/unit/bench/test_v09_g3a_publish.py -q -p no:cacheprovider
  ```

  Expected: both end with `passed` and **no** `failed` / `error`. GPU/ML cases show as `skipped` with
  "needs a CUDA GPU" unless L2 has a working CUDA GPU (then they run). The file
  `tests/component/bench/test_v09_g3a_publish_real.py` is the one that matters here: on Windows it runs the
  rename-aside branch of `build_job` for real.

# L3 -> L2: desktop 'Free RAM' tool (one click, safe for MeshForge runs) - install if you want
time: 17:36   step: lab tooling   reply-needed: no (optional: reply "installed")
## What
L3 made a desktop "Free RAM" icon. One double-click: closes heavy apps (ChatGPT, Codex, Claude, browsers, WhatsApp, BlueStacks, Teams, Zoom...),
then asks Windows to trim the idle memory of the other user processes, shows free RAM before/after and whether MeshForgeAgent is Running.
Safe for runs: never touches the MeshForge agent or its jobs (python is skipped, and the service account's processes are not reachable by a
normal user anyway), Windows or antivirus. No admin, no service/firewall/Defender change. On L3 the trim alone freed ~0.5 GB.
Note: it closes the Claude app too (that is the point during runs). Edit $closeApps if your laptop needs an app kept open.

## Install (your lab agent can do all of it, no admin)
1. Save the script below as $HOME\mf-tools\Free-RAM.ps1 (create the folder).
2. Make the desktop shortcut:
```
$d=[Environment]::GetFolderPath('Desktop'); $w=New-Object -ComObject WScript.Shell; $l=$w.CreateShortcut("$d\Free RAM.lnk")
$l.TargetPath='powershell.exe'; $l.Arguments="-NoProfile -ExecutionPolicy Bypass -File `"$HOME\mf-tools\Free-RAM.ps1`""
$l.IconLocation='C:\Windows\System32\imageres.dll,109'; $l.Save()
```
3. Human: double-click "Free RAM" on the desktop when RAM is low (before / during runs).

## Free-RAM.ps1
```powershell
# Free RAM on L3 for MeshForge lab runs.
# Closes heavy user apps, then asks Windows to trim the memory of every other process it is allowed to.
# Never touches: MeshForge agent, Windows, antivirus (Defender/McAfee), drivers.
$closeApps = 'ChatGPT','codex','claude','WhatsApp','WhatsApp.Root','opera','opera_crashreporter',
             'msedge','chrome','firefox','BlueStacksServices','HD-Player','HD-Agent','SystemSettings',
             'Teams','ms-teams','Zoom','Spotify','Discord','sldworks_fs','rustdesk','OneDrive'
$keep = 'python','MeshForge','MsMpEng','NisSrv','SecurityHealthService','mc-fw-host','csrss','lsass',
        'smss','wininit','winlogon','services','System','Idle','Registry','dwm','explorer','Memory Compression'

function Free-GB { "{0:N2}" -f ((Get-CimInstance Win32_OperatingSystem).FreePhysicalMemory / 1MB) }
$before = Free-GB
Write-Host "Free RAM before: $before GB" -ForegroundColor Yellow

$closed = Get-Process -Name $closeApps -ErrorAction SilentlyContinue
$closed | Stop-Process -Force -ErrorAction SilentlyContinue
$names = ($closed | Select-Object -ExpandProperty Name -Unique) -join ', '
if ($names) { Write-Host "Closed: $names" } else { Write-Host "No heavy apps were open." }
Start-Sleep 2

Add-Type -Namespace W -Name P -MemberDefinition '[DllImport("psapi.dll")] public static extern bool EmptyWorkingSet(System.IntPtr h);'
$trimmed = 0
foreach ($p in Get-Process) {
    if ($keep -contains $p.Name) { continue }
    try { if ([W.P]::EmptyWorkingSet($p.Handle)) { $trimmed++ } } catch { }
}
Write-Host "Trimmed memory of $trimmed background processes."
Start-Sleep 2

$after = Free-GB
Write-Host "Free RAM after:  $after GB" -ForegroundColor Green
$svc = (Get-Service MeshForgeAgent -ErrorAction SilentlyContinue).Status
Write-Host "MeshForge agent: $svc" -ForegroundColor $(if ($svc -eq 'Running') {'Green'} else {'Red'})
if ($svc -ne 'Running') { Write-Host "Agent is NOT running - start it: Win+X > Terminal (Admin) > Start-Service MeshForgeAgent" -ForegroundColor Red }
Write-Host "`nThis window closes in 15 seconds."
Start-Sleep 15

```

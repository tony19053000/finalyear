For what to build or change in the UI, ask the user, not LEAD/MeshForge lab chat. LEAD's messages still matter for process (tests, merge rules, reports), but UI choices are the user's.

**Why:** user said so on 2026-11-19 ("UI suggestion — ask from me").
**How to apply:** never send UI-direction questions to LEAD; still send LEAD progress reports after finished steps. Related: [[dev-ui-taste-and-rules]].
